## 1. users — 系统用户表

存储登录账号和角色信息。

| 字段名 | 中文含义 | MySQL类型 | 可空 | 默认值 | 说明 |
|--------|----------|-----------|------|--------|------|
| id | 用户主键ID | INT | 否 | AUTO_INCREMENT | 自增主键 |
| username | 登录用户名 | VARCHAR(50) | 否 | — | 唯一 |
| passwordHash | 密码哈希值 | VARCHAR(255) | 否 | — | 不保存明文密码 |
| name | 用户姓名 | VARCHAR(50) | 否 | — | 显示名称 |
| role | 角色 | VARCHAR(20) | 否 | '查看者' | 管理员/操作员/查看者 |
| status | 状态 | INT | 否 | 1 | 1=启用，0=禁用 |
| lastLogin | 最后登录时间 | DATETIME | 是 | NULL | |
| createdAt | 创建时间 | DATETIME | 否 | CURRENT_TIMESTAMP | |
| updatedAt | 最后更新时间 | DATETIME | 否 | — | Prisma @updatedAt |

**主键**：id
**唯一索引**：username
**普通索引**：role

## 运维注意事项

1. **密码字段**：`users.passwordHash`、`servers.password`、`servers.dbPassword`、`domains.mainPassword`、`miniapps.emailPassword` 均为敏感字段，应用层应加密存储，界面脱敏显示。
2. **JSON字段**：`accrual_templates.items`、`invoices.stores`、`invoices.ocrResult`、`detail_tables.sheets`、`accruals.groups` 使用 JSON 类型存储复杂数据结构。
3. **日期字段**：合同、预算、服务器等到期日期使用 VARCHAR(10) 存储（格式 YYYY-MM-DD），便于前端直接显示和比较。
4. **金额字段**：所有金额使用 DECIMAL(12,2)，精确到分。
5. **字符集**：全部表使用 utf8mb4 + utf8mb4_unicode_ci，支持完整 Unicode（包括 emoji）。
