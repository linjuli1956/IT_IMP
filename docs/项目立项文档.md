## 一、项目背景与目标

### 1.1 项目背景

泰兴超市信息部日常需要处理通讯费发票报销、计提费用核算、合同管理等工作。本项目搭建一个轻量级内部 Web 管理平台 + EXE部署配置工具，通过 OCR 自动识别、计提模板自动套用、费用分摊等能力，将核心业务数据集中管理，并支持方便地拷贝到其他 Windows 机器部署。

### 1.2 项目目标与约束

| 目标 | 说明 |
|------|------|
| **V0.01** | 跑通发票报销全流程 + 合同管理(含到期提醒) + 首页数据大屏 + 费用分摊规则引擎 + EXE配置部署工具 |
| **V0.1~V1.0** | 费用分摊增强、客户管理、数据导出、看板增强 |
| **体积约束** | EXE配置器 ≤15MB，整体项目 ≤100MB |
| **部署约束** | Windows 免安装，整个文件夹拷贝即用 |

### 2.2 EXE配置部署工具

| 功能点 | 说明 |
|--------|------|
| 远程数据库配置 | 配置远程 MySQL 主机(默认空)/端口(3306)/用户名(root)/密码/数据库名(it_imp) |
| 密码加密保存 | 数据库密码使用 Windows DPAPI 加密保存在本机 config.json，不写入明文文件/`.env`/日志 |
| 测试连接 | 先测试 MySQL 服务器连接，再检查目标数据库是否存在，返回明确状态 |
| 数据库状态显示 | 实时显示：未初始化/已初始化/连接失败 + 已执行迁移数量 + 最近初始化/升级时间 |
| 初始化数据库 | 首次部署使用。创建数据库(如不存在) → Prisma migrate deploy → db seed → 更新状态。初始化前二次确认，明确显示远程主机和数据库名。已初始化后不重复执行 seed |
| 升级数据库 | 版本更新使用。仅执行 Prisma migrate deploy，不执行 seed，不清空数据。无待执行迁移时提示「数据库已是最新版本」。升级前二次确认。服务运行时自动停止、升级后重启 |
| 端口配置 | 配置 Web 服务端口号 |
| 启动/停止 | 启动和停止 Web 平台服务，启动时通过环境变量注入数据库连接信息(含解密密码) |
| 日志输出 | 实时展示服务运行日志和数据库操作日志，日志中不打印密码或完整连接字符串 |
| 便捷部署 | 整个文件夹拷贝到其他 Windows 机器即可使用，不需要安装本机 MySQL |

### 2.3 发票费用报销流程（核心）

```
基础配置 → 上传发票 → 上传明细表(可选) → 生成计提表 → 下载/打印
```

#### 步骤1：基础配置

**部门门店机构管理**（13个预设机构）：总部信息部、团购部、门店A、门店B、门店C、门店D、门店E、门店F、门店G、门店H、物流中心A、物流中心B、门店I。支持新增/编辑/禁用/删除/排序。门店数据通过 composable(useStoreData) 共享，计提模板等模块从同一数据源获取选项。

**计提表模板**：每个运营商+门店一套，含序号、承担部门、名称、费用、备注。
- 电信模板“名称”列填写演示号码（如 `DEMO_PHONE`），用于匹配明细表
- 联通/移动模板"名称"列写费用类型（如 `宽带固话`），直接填发票金额

**电信计提逻辑（倒推计算）**：
- 明细表多 sheet（不同门店在不同 sheet）
- 号码行：直接从明细表取"应收合计"
- 非号码行（如"固话及其他费用"）：发票总额 - 模板中其他号码行费用之和

**客户管理**：添加合同相关的客户/合作方。

#### 步骤2：上传发票

拖拽 PDF/ZIP 到上传区，选运营商+费用月(可选)+门店（支持多选，一张发票可关联多个部门）。ZIP 自动解压。OCR 识别后弹窗人工确认，每张发票可独立分配门店。自动重命名：`{运营商}_{年月}_{序号}_{承担部门}_{金额}.pdf`（多部门用顿号连接）。创建批次，批次号格式：`{年月}{运营商缩写}{2位序号}`（如 `202606DX01`，缩写：电信DX/联通LT/移动YD/广电GD）。单次最多10张。

#### 步骤3：上传明细表（可选）

拖拽运营商 XLS 明细表，选运营商+费用月。解析后存入数据库，前端展示号码对应费用。

**电信明细表格式**：业务号码 | 月基本费 | 语音通信费 | 短信彩信费 | 综合信息服务费 | 优惠费用 | 应收合计

#### 步骤4：生成计提表

| 计提方式 | 逻辑 | 适用 |
|---------|------|------|
| 按明细表生成 | 号码行匹配明细表取应收合计；非号码行倒推计算 | 电信 |
| 按发票生成 | 直接用发票价税合计填模板首行 | 移动、联通 |
| 按分摊方案生成 | 使用费用分摊方案，支持四种分摊方式（固定/比例/数量/手动），跨门店分摊 | 所有运营商 |

多门店批次按购买方分组自动生成。制表人自动填入。

#### 步骤5：下载/打印计提表

下载 Excel 或 A5 打印（A4纸上下排2张A5，内容充满A5区域确保打印清晰，裁剪线分隔）。报销说明支持模板级可配置，支持单条复制和合计复制，用于钉钉审批。

**报销说明配置**（每个计提模板中单独配置）：
- 预设格式：提供4种常用格式模板（分摊明细型、汇总简明型、年费描述型、分项列举型）
- 自定义格式：用户可输入变量占位符自定义格式
- 可用变量：`{门店}` `{年月}` `{运营商}` `{费用类型}` `{金额}` `{部门}` `{号码数}`
- 承担部门支持多选，多部门时按部门分行显示分摊金额
- 预览功能：模板编辑界面提供实时预览，用户配置明细行后即可查看报销说明最终输出效果，所见即所得，避免生成计提表后才发现格式问题

**格式统一规范**：
所有预设格式开头统一为 `{年月}{运营商}{部门/门店}` 顺序。原因：实际使用中各模板格式差异较大，财务在钘钉审批时需逐条辨别格式，统一开头后可快速定位费用归属期、运营商和部门，提升核对效率。

**预设格式说明及样例**（统一以 {年月}{运营商}{部门} 开头）：
1. 分摊明细型 — 适用于多部门分摊场景，逐项列出各部门承担的费用类型和金额，末尾单独一行总计：
   `2026年03月中国电信总部信息部、团购部费用分摊明细：团购部承担 (5 个手机号码)：329.0 元；总部信息部承担固话及其他费用：2307.2 元；`
   `总计：2636.2 元；`
2. 汇总简明型 — 适用于单门店费用汇总，列出费用类型和总金额：
   `2026年03月中国移动宝龙店费用，家宽、固话（含话费）：498.00元`
3. 年费描述型 — 适用于年度宽带费用，描述用途和年费金额：
   `2026年07月中国电信昭平榕园店使用宽带（主用于办公、WiFi、收银等）年费：昭平榕园店宽带1条，年费1440元；`
4. 分项列举型 — 适用于多项费用分别列明，逐项列出后合计：
   `2026年07月中国联通总部信息部宽带固话1条：0.00元，总部信息部企业专线1条：0.00元。合计：0.00元`

**打印布局**：
- A4纸（210×297mm）上下排布2张A5（各210×148mm）
- 计提表内容充满整个A5区域，避免留白过多导致字太小
- 裁剪线分隔，用户打印后对半裁剪

#### 步骤6：发票打印

发票为 A5 尺寸，支持 2 张排布在 1 张 A4 纸上，打印后裁剪。

| 功能 | 说明 |
|------|------|
| 单张打印 | 选1张发票，预览后打印 |
| 批量打印 | 勾选多张，每2张排一页A4，一键打印 |
| 打印预览 | 打印前显示预览，确认排布效果 |
| 技术方案 | pdfjs-dist 渲染PDF为图片 → CSS排布2张A5到A4 → 浏览器原生打印，无需额外插件 |

### 2.4 合同管理

上传 PDF + 填写标题/客户/类型/金额/签订日期/到期日期。类型：宽带/设备采购/项目/采购/维保。含到期提醒。

### 2.5 信息部预算管理

公司每个财年编制通讯费预算，目前覆盖通讯费，未来可拓展设备、维保等预算类型。

| 功能 | 说明 |
|------|------|
| 预算编制 | 按财年、按门店、按运营商设置年度/月度预算金额 |
| 预算执行 | 实际费用 vs 预算对比，图表展示执行率 |
| 预算预警 | 超预算或接近预算时提醒 |
| 预算类型 | V0.01仅通讯费，后续可拓展设备/维保/项目等 |
| 预算维度 | 财年 → 门店 → 运营商 → 月度 |
| 数据来源 | 26财年预算54条明细（来自Excel），覆盖11个门店/部门 |
| 视图模式 | 汇总视图（门店×月份矩阵+热力图5档分色+门店分类色标）+ 明细视图（按门店折叠+费用范围日期选择器+复制按钮）+ 执行对比（预算vs实际进度条） |
| 财年支持 | 明细按财年区分，支持"生成下个财年"克隆当前财年全部明细到下一年 |
| 热力图分档 | 按绝对金额5档分色：红≥2000/橙≥700/黄≥500/浅黄≥400/蓝<400，高值加粗 |
| 门店分类 | 总部(橙)/门店(蓝)/物流(绿)三分类，左侧彩色标签 |
| 费用范围 | 月范围日期选择器(el-date-picker monthrange)，存储格式YYYY-MM~YYYY-MM |
| 复制功能 | 明细行支持复制按钮，预填被复制项数据(ID=0)，修改差异后保存即新增 |

### 2.7 IT资产管理

管理泰兴超市信息部的IT基础设施账号凭证，包括多平台服务器、域名和小程序。

| 功能 | 说明 |

## 三、技术路线

### 3.1 技术栈选型

| 层次 | 技术选型 | 体积 | 理由 |
|------|---------|------|------|
| **桌面配置工具** | Go + Wails v2 | 8-15MB | 编译单EXE，WebView2免安装，UI用Web技术 |
| **全栈框架** | Nuxt 4（Vue 3） | 15-25MB | 前后端一体，Vue 简单 |
| **UI 组件库** | Element Plus（浅色） | - | 组件齐全，中文文档好 |
| **图表库** | ECharts（浅色） | - | 数据大屏标配 |
| **数据库** | MySQL 8.0（远程服务器） | - | 远程部署，不在本机安装，EXE 配置工具远程连接 |
| **ORM** | Prisma | - | 可视化操作，自动建表 |
| **OCR 引擎** | RapidOCR（ONNX） | 15-25MB | 轻量，比PaddleOCR小很多 |
| **PDF 处理** | pdfjs-dist | - | PDF转图片供OCR + 发票打印排布 |
| **压缩包** | jszip | - | 自动解压ZIP |
| **Excel 处理** | ExcelJS / SheetJS | - | 计提表导出 + 明细表解析 |
| **打印** | CSS @media print + pdfjs-dist | - | 计提表A5排A4 + 发票2张A5排A4，无需额外插件，支持预览和批量打印 |
| **认证** | JWT | - | 轻量级 |
| **Web运行时** | Bun | 10-20MB | 比Node.js小，运行Nuxt服务 |
| **整体预估** | | **~53-90MB** | **≤100MB** |

### 3.3 前端风格规范

浅色统一风格，全站控件复用、字体统一。拖拽上传。A5打印居中。

### 3.3.1 页面说明规范

每个功能页面顶部（PageHeader 下方）应提供 `el-alert` 使用说明区块，帮助用户快速理解页面用途和操作方式：

- 统一样式：`el-alert type="info" :closable="false" show-icon`，标题为“使用说明”
- 内容为编号列表（1. 2. 3. ...），每条一句话说明一个要点
- 4-6条为宜，涵盖：页面用途、核心操作步骤、数据联动关系、注意事项
- 首页仪表盘、登录页等自解释页面无需添加

各页面说明内容规划：

| 页面 | 说明要点 |
|------|----------|
| 部门门店机构管理 | 管理名称和排序；数据同步至其他模块；禁用后不出现在下拉选项；按序号排列 |
| 客户管理 | 管理合作方信息；6种预设类型+自定义；独有配色标识；合同管理引用此处数据 |

### 4.2 关键设计说明

- **明细表分两层存储**：`carrier_details`（导入记录）+ `carrier_detail_items`（号码明细）
- **电信计提倒推**：非号码行费用 = 发票总额 - 号码行费用之和
- **明细表多sheet**：不同门店在不同sheet，解析时需遍历所有sheet
- **模板"名称"列**：电信存号码匹配明细表；联通/移动存费用类型

## 六、部署与运维

- **部署环境**：Windows（免安装）
- **配置工具**：EXE配置器（≤15MB）
- **便捷部署**：整个文件夹拷贝到其他Windows机器，EXE配置器重新配置即可
- **数据库**：MySQL 8.0 远程实例（不在本机安装 MySQL，通过 EXE 配置远程连接信息）
- **数据库密码安全**：使用 Windows DPAPI 加密保存在本机，不写入明文配置文件/`.env`/日志
- **数据库初始化**：EXE 点击「初始化数据库」创建数据库+迁移+seed；日常启动不重复建表/seed
- **数据库升级**：EXE 点击「升级数据库」执行 Prisma migrate deploy，仅更新表结构
- **OCR**：RapidOCR本地运行
- **整体体积**：≤100MB
- **备份**：MySQL每日备份 + 发票文件备份 + Git版本管理
