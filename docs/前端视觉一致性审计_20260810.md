## 五、域名/小程序 Drawer 样式与其他模块对比

### 5.1 域名/小程序 Drawer 结构（样板）

```
AssetDetailDrawer
```

| 维度 | 域名/小程序 | 服务器 | 网络设备 |

## 八、阶段 1 样板选择建议

## 九、审计结论

### 9.1 整体评价

项目已建立完整的 CSS 变量令牌体系（`tokens.css` 194 行 + `global.css` 272 行），覆盖主色/功能色/语义色板/字号/间距/圆角/阴影/侧栏等维度，令牌使用合规率约 **85%**。共享组件库覆盖 PageHeader / StatCard / CrudTable / AssetTable / AssetDetailDrawer / ServiceAssetCard / EmptyState 等核心组件，复用率良好。

主要不足集中在：
1. **按钮层级**：部分页面违反"一页一主按钮"规则
2. **行操作模式**：3-4 个按钮平铺，未统一为"文字按钮+更多菜单"
3. **权限守卫**：支付/发票/合同 3 个页面缺少 `canEdit` 控制
4. **重复 CSS**：约 7 组 scoped 样式在多页面重复定义
5. **空态/弹窗宽度/筛选栏类名**：存在 2-3 套方案并存
6. **硬编码色值**：6 处需修复（P1×2 + P2×4）

### 9.2 与 Vben Admin 风格的差距

| Vben 特征 | 当前状态 | 差距 |
|-----------|----------|------|
| 简洁克制 | ⚠️ | 预算/支付 description 过长；服务器 2 个 primary 按钮 |
| 专业后台 | ✅ | 深色侧栏 + 浅内容区已有；令牌体系完整 |
| 标题中性色 | ✅ | PageHeader title 用 `--text-primary` |
| 平台色仅资产类型 | ⚠️ | `--color-warning` 与 `--color-primary` 同值，需分离 |
| 状态色仅正常/停用/报废/到期/告警 | ✅ | 基本遵守 |
| 一页一主按钮 | ⚠️ | 服务器/预算违反 |
| 行操作文字按钮+更多 | ⚠️ | 仅系统用户达标 |
| 统一 PageHeader/Tag/Card/Table/Drawer/Dialog | ⚠️ | 组件存在但不完全统一（3 套表格、2 套空态） |
