> 版本：V0.05 | 日期：2026-07-27  
> 核心原则：先定统一规则，搭可运行骨架，跑通后再逐步加功能

## 零、开发宪法（强制规范）

> **此章节为全项目最高优先级规范，所有开发者（含 AI Agent）必须严格遵守。**
> 违反任何一条都视为代码缺陷，必须在合并前修复。

### 第1条 颜色零硬编码

- **禁止**在 `.vue` / `.css` / `.scss` / `.ts` 文件的任何位置出现硬编码十六进制颜色值（如 `#E6A23C`、`#F0F9EB`）
- **包括但不限于**：CSS 属性、`:style` 绑定、JS/TS 中的 `vars` 对象、`const colors = [...]` 数组
- **必须**使用 `tokens.css` 中定义的 CSS 变量，如 `var(--color-primary)`、`var(--color-success-light)`
- **唯一例外**：ExcelJS / ECharts 等 JS 库的配置对象中无法使用 CSS 变量，允许使用 hex 值，但**颜色值必须与 `tokens.css` 中的定义一致**，并在代码注释中标注对应的变量名

```typescript
// ❌ 禁止
const vars = {
  primary: 'var(--color-primary)',
  successLight: '#F0F9EB',  // 硬编码！
}

// ✅ 正确
const vars = {
  primary: 'var(--color-primary)',
  successLight: 'var(--color-success-light)',
}
```

### 第2条 字号零硬编码

- **禁止**在 CSS 中出现硬编码 `font-size` 值（如 `font-size: 14px`、`font-size: 12px`）
- **必须**使用 `tokens.css` 中定义的字号变量
- 可用变量：`--font-size-title`(18px)、`--font-size-subtitle`(16px)、`--font-size-body`(14px)、`--font-size-small`(13px)、`--font-size-mini`(12px)、`--font-size-micro`(11px)、`--font-size-display`(28px)、`--font-size-large`(22px)、`--font-size-icon`(20px)
- 如需未定义的字号，**先在 `tokens.css` 中新增变量**，再在页面中使用

### 第3条 间距/圆角/阴影零硬编码

- `margin` / `padding` / `gap` 优先使用间距变量（`--spacing-*`）
- `border-radius` 必须使用圆角变量（`--radius-*`）
- `box-shadow` 必须使用阴影变量（`--shadow-*`）
- 如需未定义的值，**先在 `tokens.css` 中新增变量**

### 第4条 新增 Design Token 流程

- 页面中需要 `tokens.css` 未定义的颜色/字号/间距时，**禁止直接硬编码**
- **正确流程**：
  1. 在 `tokens.css` 的 `:root` 中新增变量定义
  2. 在页面中引用 `var(--新变量名)`
  3. 同步更新本文档第二章 Design Token 清单

### 第5条 Composable 数据源模式

- 每个业务模块的数据源必须封装为 `composables/use{Module}Data.ts` 文件
- **文件结构必须包含**：
  1. `import type { XxxItem } from '~/types/xxx'` + `export type { XxxItem }`（类型 re-export）
  2. 模块级常量（如选项数组、映射表）用 `export const` 导出
  3. 预设假数据用 `const presetXxx: XxxItem[] = [...]` 定义
  4. 单例状态用 `const xxxList = ref<XxxItem[]>([...presetXxx])` 定义（模块级，非函数内）
  5. CRUD 函数（`addXxx` / `updateXxx` / `deleteXxx`）定义在模块级
  6. `export function useXxxData()` 返回所有状态和函数
- **禁止**在页面组件内直接定义 `ref` 数据源，必须通过 composable 获取

### 第6条 类型定义模式

- 每个业务模块的类型定义必须独立文件 `types/{module}.ts`
- `types/index.ts` 统一 re-export 所有类型
- Composable 文件中 `import type` from `~/types/xxx` 并 re-export
- **禁止**在 composable 或页面中内联定义 `interface`（除非仅限当前文件使用的局部类型）

### 第7条 组件复用强制

- 同类 UI 结构出现超过 **2次**，**必须**封装为可复用组件
- 通用组件放 `components/common/`，业务组件放 `components/{模块名}/`
- 组件必须使用 `<script setup lang="ts">` + `<style scoped>`
- 组件内样式**同样遵守第1~3条**（零硬编码颜色/字号/间距）

### 第8条 页面结构强制

- 每个功能页面必须包含：
  1. `<PageHeader>` 组件（标题 + 操作按钮插槽）
  2. `<el-alert>` 使用说明（type="info"，不可关闭，show-icon）
  3. 主内容区（表格/表单/图表）
  4. 新增/编辑弹窗（`<el-dialog>` + `<el-form>` + 表单校验）
- 列表页面的表格**必须**使用 `<CrudTable>` 组件，禁止手写 `el-table` + 分页

### 违规自检清单

提交代码前，**逐项检查**：

- [ ] 全局搜索 `#[0-9A-Fa-f]{3,8}` — 确认无 CSS/JS 中的硬编码颜色（Excel/ECharts 配置除外）
- [ ] 全局搜索 `font-size:.*px` — 确认无硬编码字号
- [ ] 全局搜索 `border-radius:.*px` — 确认无硬编码圆角
- [ ] 新增页面是否使用了 `PageHeader` + `el-alert` + `CrudTable`
- [ ] 新增数据源是否遵循 composable 单例模式
- [ ] 新增类型是否独立文件 + index.ts 导出

| 维度 | 决策 |
|------|------|
| 主题 | 浅色 |

## 四、组件样式规范

### 4.1 按钮

| 类型 | 样式 | 使用场景 |
|------|------|---------|
| 主操作 | 橙色实心 | 提交、保存、生成 |
| 次操作 | 白色边框 | 取消、返回 |
| 成功操作 | 绿色实心 | 启动、确认 |
| 危险操作 | 红色实心 | 删除、停止 |
| 文字按钮 | 纯文字 | 表格内操作 |

- 尺寸：默认 `default`，表格内用 `small`
- 圆角：4px
- hover：颜色加深 + 阴影

### 4.2 表格

- 行高：48px（标准型）
- 表头：浅灰背景 `--bg-page`，字重600
- 斑马纹：奇数行白色，偶数行 `--bg-hover`
- 边框：仅水平线 `--border-lighter`
- hover行：背景 `--bg-hover`
- 操作列：文字按钮，间距8px

### 4.3 表单

- label宽度：100px（统一）
- 输入框高度：32px
- 必填项：label前加红色 `*`
- 校验错误：输入框红色边框 + 下方红色提示
- 表单项间距：18px

### 4.4 弹窗

- 圆角：8px
- 阴影：`--shadow-dialog`
- 标题栏：18px字重600 + 底部分割线
- 底部按钮：右对齐，间距12px
- 动画：淡入 + 轻微上移（150ms）

### 4.5 卡片

- 背景：白色 `--bg-card`
- 圆角：8px
- 阴影：`--shadow-card`
- 内边距：16px
- hover：阴影加深 `--shadow-hover`

### 4.6 指标卡片（首页大屏）

- 高度：80px
- 布局：左侧图标 + 右侧数值和标题
- 数值：`--font-size-display`(28px) 字重600 主色
- 标题：13px --text-secondary
- 背景：白色 + 左侧4px主色竖条

## 五、交互规范

### 5.1 加载状态

| 场景 | 表现 |
|------|------|
| 表格加载 | 表格区域显示 loading 遮罩 |
| 按钮提交 | 按钮显示 loading 图标，禁用 |
| 页面切换 | 顶部进度条（橙色） |
| 数据计算 | 区域内 loading 文字"正在生成..." |

### 5.2 空状态

| 场景 | 表现 |
|------|------|
| 表格无数据 | 居中图标 + "暂无数据"文字 |
| 上传区空 | 拖拽提示 + 虚线边框 |
| 日志空 | "暂无日志"灰色文字 |

### 5.3 操作反馈

| 类型 | 表现 |
|------|------|
| 成功 | ElMessage success，3秒自动消失 |
| 失败 | ElMessage error，不自动消失，需手动关闭 |
| 警告 | ElMessage warning，3秒消失 |
| 确认操作 | ElMessageBox confirm 弹窗 |

### 5.4 拖拽上传交互

```
默认状态：虚线边框 + 拖拽提示文字
拖入状态：边框变橙色 + 背景变浅橙 + "松开以上传"
上传中：进度条 + 文件名 + 取消按钮
上传完成：文件列表 + 状态标签
上传失败：红色提示 + 重试按钮
```

### 5.5 动画规范

| 元素 | 动画 | 时长 |
|------|------|------|
| 弹窗 | 淡入 + 上移 | 150ms |
| 下拉菜单 | 淡入 + 下移 | 100ms |
| 标签页切换 | 淡入 | 100ms |
| 按钮 hover | 背景色渐变 | 200ms |
| 卡片 hover | 阴影渐变 | 200ms |
| 图表加载 | 数据动画展开 | 600ms |

## 六、组件复用规则

**核心原则：同类UI结构出现超过两次，必须封装为可复用组件。**

### 6.1 组件封装清单

| 组件名 | 封装原因 | 使用页面数 |
|--------|---------|-----------|
| `PageHeader` | 页面标题+操作按钮，每个页面都有 | 12+ |
| `CrudTable` | 增删改查表格，门店/供应商/用户/合同都用 | 4+ |
| `EditDialog` | 编辑弹窗（表单+确认），多处使用 | 4+ |
| `DragUpload` | 拖拽上传，发票/明细表/合同都用 | 3+ |
| `StatCard` | 指标卡片(左侧4px主色竖条+图标+数值+标签)，首页/预算/支付都用 | 3+ |
| `ChartCard` | 图表卡片（标题+ECharts容器），首页4个 | 4 |
| `OcrConfirmDialog` | OCR确认弹窗 | 1（预留复用） |
| `PrintPreview` | A5打印预览 | 1（预留复用） |
| `ReimbursementText` | 报销说明+复制按钮 | 2+ |
| `SensitiveValue` | 敏感信息脱敏显示（密码/账号），眼睛图标切换 | 3+ |
| `FeeItemEditor` | 费用项编辑器（费用类型/金额来源/分摊方式），费用分摊方案配置 | 1+ |
| `AllocationEditor` | 分摊明细编辑器（门店+比例/数量/金额），费用分摊方案配置 | 1+ |

### 6.2 组件命名规范

- PascalCase 命名
- 通用组件放 `components/common/`
- 图表组件放 `components/charts/`
- 业务组件放 `components/business/`

### 6.3 组件开发规范

- 所有组件用 `<script setup>` 语法
- Props 用 `defineProps` + TypeScript 类型
- 事件用 `defineEmits`
- 样式用 `<style scoped>`，引用 Design Token 变量

## 七、框架组件库与模块边界

### 7.1 框架组件库选型

**核心原则：不要用原生开发，所有 UI 用成熟组件库。**

#### 核心框架

| 用途 | 选型 | 说明 |
|------|------|------|
| 全栈框架 | Nuxt 4（Vue 3） | 前后端一体，自动路由，SSR/SPA 可选 |
| UI 组件库 | Element Plus | 组件齐全，中文文档好，主题可定制 |
| 图表库 | ECharts | 数据大屏标配，浅色主题 |

#### 辅助库

| 用途 | 选型 | 说明 |
|------|------|------|
| 状态管理 | Pinia | Nuxt 4 官方推荐，替代 Vuex |
| 组合式工具 | @vueuse/core | useDark/useLocalStorage 等实用 hooks |
| 日期处理 | dayjs | 轻量，API 兼容 moment |

#### 业务库（按需引入）

| 用途 | 选型 | 说明 |
|------|------|------|
| Excel 处理 | ExcelJS | 预算汇总导出 + 计提表导出 |
| PDF 处理 | pdfjs-dist | PDF 转图片供 OCR |
| 压缩包 | jszip | 自动解压 ZIP |

#### 开发工具

| 用途 | 选型 | 说明 |
|------|------|------|
| 类型系统 | TypeScript | 类型安全，IDE 智能提示 |
| HTTP 请求 | Nuxt 内置 $fetch | 无需额外安装 axios |
| 代码规范 | ESLint + Prettier | 统一代码风格 |

```
│   ├── useBudgetData.ts        # 预算数据源
│   ├── useServerData.ts        # 服务器数据源
│   ├── useFeeSchemeData.ts     # 费用分摊方案数据源
│   └── ...                     # 每个模块一个 use{Module}Data.ts
├── layouts/
│   └── default.vue             # 主布局
├── pages/                      # 页面（按模块分目录）
├── types/                      # 类型定义（按模块分文件）
│   ├── index.ts                # 统一 re-export
│   ├── store.ts
│   ├── invoice.ts
│   ├── budget.ts
│   ├── server.ts
│   └── ...                     # 每个模块一个 {module}.ts
├── nuxt.config.ts
└── package.json
```

### 7.3 模块边界定义

**核心原则：功能模块分离，避免混乱。每个模块有自己的页面、组件、数据源、类型。**

| 代码类型 | 存放规则 | 示例 |
|---------|---------|------|
| **页面** | 按模块分目录 | `pages/invoices/upload.vue` |
| **通用组件** | 放 `components/common/` | `PageHeader`, `CrudTable`, `SensitiveValue` |
| **业务组件** | 放 `components/{模块名}/` | `components/invoice/DragUpload.vue` |
| **图表组件** | 放 `components/charts/` | `ChartCard` |
| **数据源** | 放 `composables/use{Module}Data.ts` | `composables/useInvoiceData.ts` |
| **类型定义** | 放 `types/{模块}.ts` | `types/invoice.ts` |
| **后端接口** | 放 `server/api/{模块}/` | `server/api/invoices/`（后端阶段） |

### 7.4 模块分离规则

| 规则 | 说明 |
|------|------|
| 功能模块独立 | 登录、发票、计提、合同等模块各自独立，不交叉 |
| 禁止跨模块引用 | 发票模块不直接引用计提模块的组件 |
| 跨模块复用提取到 common | 多个模块共用的组件放 `components/common/` |
| 同类UI超过两次封装 | 避免重复代码 |
| 数据源与类型对应 | `composables/useInvoiceData.ts` ↔ `types/invoice.ts` |
| 数据源与页面对应 | `composables/useInvoiceData.ts` 对应 `pages/invoices/` |

## 十、各页面规划（简要）

### 10.1 首页 `/`
4个指标卡片 + 费用趋势折线图 + 门店占比饼图 + 类型分布柱状图 + 运营商排名条形图 + 合同到期提醒列表

### 10.2 门店管理 `/config/stores`
CrudTable：名称、排序、状态、操作。新增/编辑弹窗：名称+排序

### 10.3 计提模板管理 `/config/templates`
模板列表（运营商+门店筛选）→ 模板编辑器（动态行：承担部门/名称/费用/备注）

### 10.4 供应商管理 `/config/suppliers`
CrudTable：名称、联系人、电话、备注

### 10.5 上传发票 `/invoices/upload`
运营商/费用月/门店多选 → DragUpload拖拽区 → OCR确认弹窗（每张发票独立分配门店）→ 创建批次（批次号：{年月}{运营商缩写}{2位序号}）

### 10.6 批次列表/详情 `/invoices/batches`
批次列表（批次号格式化显示+生成计提/再次生成）→ 批次详情（发票列表+多部门标签+报销说明复制+生成计提表入口）

### 10.7 明细表管理 `/details`
导入列表 → 详情（号码费用表格，标注匹配部门）

### 10.8 生成计提表 `/accruals/generate/[id]`
选模板+计提方式 → 生成 → 计提表详情（A5打印预览+下载Excel）

### 10.9 合同管理 `/contracts`
CrudTable：标题/供应商/类型/金额/日期/状态。到期30天内标红

### 10.10 预算管理 `/budget`
三视图：汇总矩阵（门店×月份，按费用范围逐月计算，11色循环行底色，竖条色标，≥2000元标红，tooltip悬停查看费用构成，导出Excel双Sheet）+ 明细视图（按门店折叠，费用范围月范围日期选择器，复制按钮预填创建）+ 执行对比（进度条+超支预警）+ 财年维度支持（生成下个财年克隆明细）

### 10.11 支付管理 `/payment`
双Tab：商户管理（9商户表格）+ 支付配置（15项配置+敏感信息脱敏+支付方式彩色tag）

### 10.12 IT资产管理 `/it/*`
三个子页面，统一使用 PageHeader + el-alert 使用说明 + 搜索 + CrudTable + SensitiveValue脱敏 + 弹窗CRUD：
- **服务器管理** `/it/servers`：本地+阿里云服务器合并管理，IP/用途/登录凭证/数据库凭证，4个概览卡片
- **域名管理** `/it/domains`：阿里云域名及主账号凭证
- **小程序管理** `/it/miniapps`：小程序名称/绑定邮箱/邮箱密码

### 10.13 登录页 `/login`
居中卡片：用户名+密码+登录按钮
