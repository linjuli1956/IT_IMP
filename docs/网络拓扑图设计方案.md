# 网络拓扑图设计方案

> 阶段：阶段 0（设计与数据方案） · 状态：待审计确认 · 日期：2026-08-10
> 适用：网络设备页"网络拓扑"辅助视图的设计依据；阶段 1 编码须严格遵循本文档。

---

## 1. 背景与目标

当前网络设备页（`it/network-devices.vue`）为台账列表模式，满足日常管理需求。但门店网络设备的物理连接关系（核心交换机→接入交换机→AP 等）无法通过列表直观表达。

本方案在**不改变现有台账列表**的前提下，新增"网络拓扑"Tab 作为辅助视图，以力导向图展示设备间的连接关系。

---

## 2. 数据方案

### 2.1 现状分析

`NetworkDevice` 模型仅记录设备属性（类型、IP、端口数、安装位置等），**不包含设备间的连接关系**。无法从现有数据自动生成真实拓扑连线。

### 2.2 新增模型：NetworkDeviceLink

```
/// 网络设备连接关系表 — 记录设备间的物理/逻辑连接
model NetworkDeviceLink {
  /// 连接关系主键ID，自增
  id              Int      @id @default(autoincrement())
  /// 源设备ID（外键→network_devices.id，删除级联）
  sourceDeviceId  Int
  /// 源端口（如 GigabitEthernet1/0/1）
  sourcePort      String   @db.VarChar(50) @default("")
  /// 目标设备ID（外键→network_devices.id，删除级联）
  targetDeviceId  Int
  /// 目标端口
  targetPort      String   @db.VarChar(50) @default("")
  /// 连接类型：上联/级联/直连/其他
  linkType        String   @db.VarChar(20) @default("直连")
  /// 备注
  remark          String   @db.VarChar(500) @default("")
  /// 创建时间
  createdAt       DateTime @default(now())
  /// 最后更新时间
  updatedAt       DateTime @updatedAt

  /// 源设备
  sourceDevice    NetworkDevice @relation("LinkSource", fields: [sourceDeviceId], references: [id], onDelete: Cascade)
  /// 目标设备
  targetDevice    NetworkDevice @relation("LinkTarget", fields: [targetDeviceId], references: [id], onDelete: Cascade)

  /// 禁止自连接（sourceDeviceId ≠ targetDeviceId）
  /// 禁止重复连接（sourceDeviceId + targetDeviceId + sourcePort + targetPort 唯一）
  @@unique([sourceDeviceId, targetDeviceId, sourcePort, targetPort], name: "unique_device_link")
  @@index([sourceDeviceId])
  @@index([targetDeviceId])
  @@map("network_device_links")
}
```

同时需在 `NetworkDevice` 模型中添加反向关系字段：

```
  /// 作为连接源的连线列表
  outgoingLinks   NetworkDeviceLink[] @relation("LinkSource")
  /// 作为连接目标的连线列表
  incomingLinks   NetworkDeviceLink[] @relation("LinkTarget")
```

### 2.3 校验规则

| 规则 | 说明 |
|---|---|
| 禁止自连接 | sourceDeviceId ≠ targetDeviceId，后端 400 |
| 禁止重复连接 | (source, target, sourcePort, targetPort) 唯一约束，后端 409 |
| 设备删除级联 | 删除设备时，该设备参与的连线自动级联删除 |
| 端口非必填 | 端口字段可为空（非网管设备无端口概念） |
| 连接类型枚举 | 上联 / 级联 / 直连 / 其他 |

### 2.4 迁移说明

- 迁移文件全部使用中文注释
- 新建 `network_device_links` 表
- 为 `network_devices` 添加反向关系字段（仅 Prisma 层面，不改表结构）
- 不删除、不修改任何现有字段

## 3. 节点色规则

节点颜色表达**设备类型**，状态仅通过边框/角标表达，两者不混淆。

| 设备类型 | 节点色 | 色值 |
|---|---|---|
| 交换机 | 蓝 | `#409EFF` |
| 路由器 | 橙 | `#E6A23C` |
| 防火墙 | 红 | `#F56C6C` |
| AP | 绿 | `#67C23A` |
| 其他 | 灰 | `#909399` |

| 设备状态 | 边框样式 | 说明 |
|---|---|---|
| 正常 | 绿色边框 2px | `borderColor: #67C23A` |
| 停用 | 灰色边框 2px | `borderColor: #909399`，节点透明度 0.5 |
| 报废 | 红色边框 2px | `borderColor: #F56C6C`，节点透明度 0.3 |

> 硬性约束：类型色填充节点内部，状态色仅用于边框；禁止用状态色替换类型色。

## 4. 交互设计

| 交互 | 实现方式 |
|---|---|
| 按门店筛选 | 门店下拉，切换后仅显示该门店设备与连线 |
| 缩放 | ECharts `roam: true` 启用滚轮缩放 |
| 拖拽浏览 | `roam: true` 启用画布拖拽；节点可拖拽重排 |
| 居中复位 | `toolbox.restore` 按钮 |
| 图例 | 按 deviceType 分类，点击可隐藏/显示某类设备 |
| 节点点击 | 未来打开 AssetDetailDrawer（阶段 1 实现） |
| 连线 hover | tooltip 显示连接类型、源端口→目标端口 |

---

## 5. 空态处理

当所选门店的设备**未配置任何连接关系**时：
- 不渲染图谱画布
- 显示 EmptyState 提示"尚未配置网络连接关系"
- 禁止伪造线路或自动推断连接

> 硬性约束：无连线数据时必须显示空态，绝不在没有数据的情况下绘制连线。

## 6. 范围与约束

### 6.1 第一版范围（只读拓扑 + 连接维护 Drawer）

| 包含 | 不包含 |
|---|---|
| 只读力导向图拓扑展示 | 自动扫描 / 自动发现 |
| 按门店筛选 + 缩放/拖拽 | 画线编辑器 |
| 图例 + tooltip | 坐标保存 / 自定义布局 |
| 连接关系维护 Drawer（增删连线） | 拓扑导出 / 截图 |
| 节点点击打开 AssetDetailDrawer | 性能监控 / 流量可视化 |

### 6.2 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 图表库 | ECharts 6 + vue-echarts 8 | 项目已安装，无需新增依赖 |
| 布局算法 | force（力导向） | 自动排布，无需保存坐标 |
| 渲染器 | CanvasRenderer | 性能优于 SVG，节点数 <100 足够 |
| 替代方案 | ~~AntV X6~~ | 重型依赖，过度设计 |

> 硬性约束：不引入 X6、G6 等重型图编辑库；ECharts graph 已满足需求。
