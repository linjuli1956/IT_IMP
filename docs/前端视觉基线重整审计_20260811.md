## 三、视觉割裂问题清单

### 问题 1：两套按钮体系并存（严重）

| 体系 | 使用页面 | 特征 |
|------|---------|------|
| **ActionButton** | 仅 `servers.vue` | variant 色彩体系（close/primary/credential/external/info），文字操作 + "更多"菜单 |
| **el-button** | 其他所有页面 | type="primary"/"danger"/"default"，标准 Element Plus 按钮 |

**影响**：servers.vue 的 Drawer Footer 与其他页面视觉风格完全不同。

### 问题 2：统计卡实现不一致（中等）

| 实现 | 使用页面 |
|------|---------|
| 自定义统计卡 | `servers.vue`（物理/虚拟/到期/保修） |
| StatCard 组件 | `domains.vue`、`miniapps.vue` |
| 无统计卡 | `network-devices.vue`、`computers.vue`、`phones.vue`、`scales.vue` |

### 问题 3：筛选栏不统一（中等）

| 实现 | 使用页面 |
|------|---------|
| AssetFilters 组件 | network-devices、computers、phones、scales |
| 手动 el-input/el-select | domains、miniapps、servers |
| 无筛选 | config/* |

### 问题 4：表格组件混用（中等）

| 实现 | 使用页面 |
|------|---------|
| AssetTable 组件 | network-devices、computers、phones、scales |
| CrudTable 组件 | domains、miniapps、config/* |
| 自定义 el-table | servers |

### 问题 5：表单弹窗不统一（低）

| 实现 | 使用页面 |
|------|---------|
| AssetFormDialog 组件 | network-devices、computers、phones、scales |
| 手动 el-dialog | domains、miniapps、servers、config/* |

### 问题 6：Drawer Footer 不统一（中等）

| 实现 | 使用页面 |
|------|---------|
| ActionButton 体系 | servers（close/primary/更多菜单） |
| el-button | domains、miniapps、network-devices |
| 仅关闭 | network-devices（拓扑触发） |

### 问题 7：行操作不统一（中等）

| 实现 | 使用页面 |
|------|---------|
| 文字操作 + "更多"菜单 | servers |
| AssetTable 内置 edit/delete | network-devices、computers、phones、scales |
| CrudTable 内置 edit/delete | domains、miniapps |

## 五、改造优先级

### P0 — 建立唯一视觉契约（阶段 B，需用户确认）

1. 定义统一的 PageHeader + 筛选栏 + 表格 + Drawer + Dialog 规范
2. 定义统一的按钮体系（决定 ActionButton 是否推广还是回归 el-button）
3. 定义统一的行操作模式（文字操作 + "更多"菜单 vs 内置按钮）

### P1 — 两个样板页（阶段 C）

| 样板 | 页面 | 模式 | 目标 |
|------|------|------|------|
| 资产台账样板 | `it/network-devices.vue` | 筛选 + 紧凑表格 + 可点击详情 Drawer | 统一 AssetFilters + AssetTable + AssetDetailDrawer + 统一行操作 |
| 服务资产卡片样板 | `it/domains.vue` | 服务资产卡片 + Drawer | 统一 ServiceAssetCard + AssetDetailDrawer + 统一行操作 |

### P2 — 批量迁移（阶段 C 之后，用户确认样板后）

1. 资产台账同模式页面：computers、phones、scales
2. 服务资产同模式页面：miniapps
3. 服务器页保留工作台特性，但复用统一规则
4. 配置 CRUD 和流程详情页：低优先级，按需迁移
