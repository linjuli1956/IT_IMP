## 六、唯一视觉契约 v0.1（待用户确认）

> 以下 8 条规则为视觉统一的基准契约，用户确认后才作为编码标准。

1. **标题中性深色；平台色只用于资产属性**
   - 页面标题、卡片标题统一使用 `var(--text-primary)`（中性深色）
   - 平台色（`var(--color-primary)` 橙色）只用于资产属性标识（如 PVE/ESXi 标签），不用于页面标题

2. **状态色只用于状态与预警**
   - `var(--color-success)` / `var(--color-warning)` / `var(--color-danger)` 只用于状态标签、到期预警、校准提醒
   - 不用于按钮、标题、装饰性元素

3. **每页一个实体主按钮；行操作统一文字操作+更多**
   - 每页最多一个 `type="primary"` 主操作按钮（新增/保存）
   - 行操作统一为"文字操作 + 更多下拉"模式，不在行内堆叠多个按钮
   - 更多菜单收纳低频操作（凭据、详情页等）

4. **Drawer 标题、宽度、信息表、Footer 统一**
   - Drawer 标题 = 资产名称
   - 宽度统一 480px（资产详情）/ 640px（编辑表单）
   - 信息表统一使用 description-list 模式
   - Footer 统一为：关闭（中性）+ 主操作（蓝色）+ 更多（下拉）

5. **ActionButton 只用于明确的 Drawer/Dialog 操作，不为颜色新增操作**
   - ActionButton 不在列表页表格行内使用
   - 不为了使用某个 variant 色而新增一个操作按钮
   - 列表页统一使用 el-button + 文字操作

6. **网络设备/电脑/固话/电子秤统一资产台账模式**
   - 统一使用 AssetFilters + AssetTable + AssetFormDialog + AssetDetailDrawer
   - 统一行操作模式（文字操作 + 更多）
   - 统一空态/加载态/错误态处理

7. **域名/小程序统一服务资产卡片模式**
   - 统一使用 StatCard + ServiceAssetCard + CrudTable + AssetDetailDrawer
   - 筛选栏从手动改为统一组件（待定义 ServiceFilters 或复用 AssetFilters）
   - 统一行操作模式

8. **服务器保留工作台特性，但复用 Header、筛选、Drawer、操作规则**
   - 服务器页保留 Tab 切换、统计卡、树形表格等工作台特性
   - Drawer Footer 复用统一规则（关闭 + 主操作 + 更多）
   - 行操作复用统一模式（文字操作 + 更多）
   - 不把服务器页的过度定制推广到其他页面
