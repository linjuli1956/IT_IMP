## 二、按钮平铺/更多判定规则

### 2.1 判定表

| 维度 | 平铺（直接显示为按钮/文字操作） | 收纳进"更多"下拉 |
|------|------|------|
| **频率** | 高频（每条记录都可能用） | 低频（偶发使用） |
| **危险性** | 安全操作（编辑、查看） | 危险操作（删除、清除） |
| **敏感性** | 非敏感（不含密码/凭据） | 敏感（凭据、密码相关） |
| **跳转** | 当前页内操作 | 外部跳转（进入管理、打开新页签） |
| **导航** | 当前页内操作 | 详情页导航（打开独立详情页） |
| **空间** | 行/Footer 空间足够（≤3 个平铺按钮） | 空间不足或超过 3 个操作 |

### 2.2 核心原则

- **"更多"不是默认答案。** 空间足够时不要多此一举。
- **单项不进下拉。** 如果"更多"里只有 1 个操作，必须平铺为按钮。
- **每页、每个 Drawer 先列操作优先级。** 不允许为了统一而机械塞进更多。
- **危险操作可平铺。** 删除按钮可以平铺（用 danger 色标识），不必强制收纳。

## 三、通用复制/导出能力规划

> **本阶段只写契约，不编码。** 先在 network-devices 样板页验证，再推广。

### 3.1 复制能力

| 能力 | 描述 | 触发方式 | 适用字段 |
|------|------|---------|---------|
| 复制单个字段 | 在表格列/Drawer 信息项上提供复制按钮 | 字段旁 `CopyDocument` 图标按钮 | IP 地址、域名、账号、资产编号、设备序列号 |
| 复制记录摘要 | 复制当前记录的关键信息为纯文本 | 行操作或 Drawer 内"复制摘要"按钮 | 格式：`名称 | 类型 | IP | 状态` |

**现有基础：**
- `ReimbursementText.vue` 已实现 `copyText()` 函数（`navigator.clipboard.writeText` + `execCommand` 降级）
- `CrudTable.vue` 已实现 `batch-copy` 事件（`showBatchCopy` prop + 批量操作栏）

**v0.2 规范：**
- 复制函数提取为 `composables/useClipboard.ts`，统一 `navigator.clipboard` + 降级逻辑
- 字段级复制：在 `AssetTable` 列配置中增加 `copyable: true` 选项，自动渲染图标
- 记录摘要复制：格式由各页面定义，但复制函数统一

**不做什么：**
- 不复制密码、凭据、Token 等敏感字段
- 不在查看者角色上显示复制按钮（`canEdit` 控制或独立 `canCopy` 权限）

### 3.2 导出能力

| 能力 | 描述 | 触发方式 | 适用范围 |
|------|------|---------|---------|
| 列表导出 | 按当前筛选条件导出 CSV/Excel | PageHeader 操作区"导出"按钮 | 所有列表页 |

**v0.2 规范：**
- 导出按钮放在 PageHeader `#actions` 插槽，位于"新增"按钮左侧
- 导出数据 = 当前筛选条件下的当前页（或全量，由后端分页参数控制）
- 导出格式优先 CSV（纯前端可完成），Excel 需后端生成或引入 `xlsx` 库
- 导出权限：管理员/操作员可导出；查看者不可导出
- **字段白名单：** 每个页面定义可导出字段列表，敏感字段（password、dbPassword、account、dbAccount）**绝不导出**

**不做什么：**
- 不导出密码、凭据、Token
- 不导出设计参考页（design/*、dev/*）
- 不在阶段 B 编码

### 3.3 敏感字段红线

| 字段 | 复制 | 导出 | 说明 |
|------|------|------|------|
| `password` | ❌ | ❌ | 服务器登录密码 |
| `dbPassword` | ❌ | ❌ | 数据库密码 |
| `account` | ❌ | ❌ | 服务器登录账号 |
| `dbAccount` | ❌ | ❌ | 数据库账号 |
| `internalIp` | ✅ | ✅ | 内网 IP |
| `externalIp` | ✅ | ✅ | 外网 IP |
| `domain` | ✅ | ✅ | 域名 |
| `serialNo` | ✅ | ✅ | 设备序列号 |
| `name` | ✅ | ✅ | 资产名称 |

## 四、Overlay 层级规则

### 4.1 当前 Token 缺口

`tokens.css` 已定义 6 个 z-index Token：

```css
--z-sidebar: 1000;
--z-header: 1100;
--z-dropdown: 2000;
--z-drawer: 3000;
--z-dialog: 4000;
--z-tooltip: 5000;
```

**缺失：**
- `--z-popover` — Popover/Popconfirm（当前依赖 Element Plus 默认值 2000，与 dropdown 冲突）
- `--z-message-box` — MessageBox（当前用魔法数字 `9999 !important` 补丁）
- `--z-message` — Message 消息提示（当前依赖 Element Plus 默认值 3000）

### 4.2 v0.2 Token 定义

> 阶段 C 编码时在 `tokens.css` 中新增以下 Token，并将 `global.css` 中的 `9999 !important` 替换为 `var(--z-message-box)`。

| Token | 值 | 用途 | 说明 |
|-------|-----|------|------|
| `--z-sidebar` | 1000 | 侧边栏 | 不变 |
| `--z-header` | 1100 | 顶部导航 | 不变 |
| `--z-dropdown` | 2000 | Dropdown 下拉菜单 | 不变 |
| `--z-popover` | 2001 | Popover/Popconfirm | 略高于 Dropdown |
| `--z-drawer` | 3000 | Drawer 抽屉 | 不变 |
| `--z-dialog` | 4000 | Dialog 对话框 | 不变 |
| `--z-message-box` | 4500 | MessageBox 确认框 | 高于 Dialog，低于 Tooltip |
| `--z-tooltip` | 5000 | Tooltip 文字提示 | 不变 |
| `--z-message` | 5500 | Message 消息提示 | 最高，始终可见 |

**层级关系图：**

```
sidebar(1000) < header(1100) < dropdown(2000) ≤ popover(2001)
  < drawer(3000) < dialog(4000) < message-box(4500) < tooltip(5000) < message(5500)
```

### 4.3 全局补丁过渡方案

当前 `global.css` 中的 `z-index: 9999 !important` 是临时补丁，**阶段 C 编码时替换为：**

```css
.el-overlay.is-message-box {
  z-index: var(--z-message-box) !important;
}
```

> `!important` 保留，因为 Element Plus 通过 JavaScript 设置 inline z-index，需要 `!important` 覆盖。但值从魔法数字改为 Token 引用。

**规则：**
- 禁止后续页面自行写新的 z-index 魔法数字
- 所有 z-index 必须引用 Token 变量
- Element Plus 组件的 z-index 通过 `:root { --el-overlay-z-index: ... }` 或 `popper-options` 控制

## 六、产品决策记录

> 以下 4 条决策由用户在 2026-08-12 审计复核中明确指示。

### 决策 1：网络设备暂不增加密码字段

**决策：** 网络设备是设备台账与拓扑模块，不增加密码字段。

**理由：** 网络设备（交换机、路由器、防火墙、AP）的登录信息保存需求尚未明确。若未来确有需求，单独规划"设备凭据"能力，不能给所有资产表顺手加密码字段。

**适用范围：** `it/network-devices.vue`、`it/computers.vue`、`it/phones.vue`、`it/scales.vue` 均不增加密码字段。

### 决策 2：收紧"更多"菜单规则

**决策：** "更多"不是默认答案。规则如下：

- 高频且空间足够 → 平铺显示（例如编辑）
- 低频、敏感、危险、外部跳转、详情导航 → 收进"更多"（例如删除、服务器凭据、进入管理、打开详情）
- 每页、每个 Drawer 都先列出操作优先级，不允许为了统一而机械塞进更多
- 更多菜单不是默认答案，空间足够时不要多此一举

**执行：** 阶段 C 编码时按 2.3 审计结果修正单项进下拉的 3 处问题。

### 决策 3：新增通用复制/导出能力（本阶段只写契约）

**决策：** 复制和导出是通用能力，但不能一次给所有菜单乱加。

- **复制：** 先做通用"复制字段/复制当前记录摘要"，用于 IP、账号、域名、设备编号等高频字段
- **导出：** 先做列表页的"按当前筛选条件导出 Excel/CSV"，并有权限与字段白名单
- **验证：** 先在 network-devices 样板页验证，再推广
- **敏感内容：** 服务器凭据等敏感内容绝不导出

**执行：** 阶段 B 只写契约（本文档第三章），阶段 C 在 network-devices 样板页编码验证。

### 决策 4：补充 Overlay 层级规则

**决策：** 当前清除确认 z-index 修复保留；阶段 B 统一 Drawer、Dialog、MessageBox、Dropdown、Tooltip 的 Token 层级。

- 当前 `global.css` 的 `z-index: 9999 !important` 保留为过渡补丁
- 阶段 C 编码时在 `tokens.css` 新增 `--z-popover`、`--z-message-box`、`--z-message` Token
- 将 `9999` 替换为 `var(--z-message-box)`
- 禁止后续页面自行写新的 z-index 魔法数字

**执行：** 阶段 B 只写契约（本文档第四章），阶段 C 编码时落地。
