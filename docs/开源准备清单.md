# 开源准备清单

> 本文档用于在创建公开 GitHub 仓库前逐项检查，确保不泄露任何内部数据。
> 最后更新：2026-07-25

---

## ⚠️ 重要提醒

**当前内部 Git 历史包含以下敏感信息，不能直接用于公开仓库：**

1. **真实门店名称**：不得进入公开源码或数据库快照
2. **真实供应商名称和电话**：不得进入公开源码或数据库快照
3. **真实手机号码**：不得进入公开源码或数据库快照
4. **真实商户号和密钥**：不得进入公开源码或数据库快照
5. **真实服务器 IP 和密码**：不得进入公开源码或数据库快照
6. **真实域名和密码**：不得进入公开源码或数据库快照
7. **MySQL 服务器 IP**：内部数据库地址（docs/开发计划文档.md）

**结论：必须创建全新的干净 Git 仓库，不能沿用旧历史。**

**⚠️ 如果 MySQL root 密码曾出现在 Git 历史中（经检查未发现），需要先更换密码。**
当前检查结果：Git 历史中未发现明文 MySQL 密码，密码通过 DPAPI 加密保存在本机 config.json（已 .gitignore）。
但仍建议在开源前更换 MySQL root 密码作为最佳实践。

## 检查清单

### 1. Git 历史

- [ ] **不沿用旧 Git 历史** — 创建全新仓库，`git init` 后一次性提交所有清理后的文件
- [ ] 使用旧仓库审计工具确认历史中不存在内部 IP、商户号、密钥或密码
- [ ] 旧仓库标记为 `internal-only`，永不推送到 GitHub

### 2. 数据分层

| 层级 | 文件 | 说明 | 公开仓库 |
|------|------|------|----------|
| 业务数据 | `data/` 和数据库 | 仓库不预置业务数据，首次部署后保持空白 | ❌ 不包含 |
| 内部文档 | `docs/副本*.xlsx` | 真实预算 Excel | ❌ .gitignore 排除 |
| 配置 | `.env` / `config.json` | 数据库地址/密码 | ❌ .gitignore 排除 |
| 示例配置 | `.env.example` | 占位符，无真实值 | ✅ 包含 |

- [x] 确认仓库不包含任何 Seed 脚本和预置业务数据

- [ ] `desktop/build/bin/` 不在仓库中（.gitignore 已排除）

## 长期规范（从现在起执行）

1. **不在代码中硬编码真实数据** — 生产业务数据只通过部署后的数据库录入
2. **仓库保持空数据** — 不提供演示 Seed 或真实 Seed；初始化执行数据库迁移并仅创建首次管理员
3. **文档不引用真实地址** — 文档中使用 `REMOTE_HOST`、`DEMO_PASSWORD` 等占位符
4. **日志不输出密码** — `sanitizeLog()` 已实现，持续维护
5. **配置通过环境变量** — 数据库连接、JWT 密钥等通过 `.env` 或 EXE 注入，不硬编码
